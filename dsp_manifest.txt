# Which of midisynth's sources this project compiles, and why the rest are out.
#
# sound/ shares midisynth's DSP by compiling its .cpp files directly rather
# than forking them. That is the only way two projects can be guaranteed to
# make the same sound from the same patch -- and scripts/run_goldens.sh proves
# it, by rendering one patch through both engines and comparing hashes.
#
# The risk of sharing by path is that midisynth grows a source we do not know
# about, and we keep building against a DSP that has moved. This file is the
# list that check_dsp_sources.sh holds midisynth to: every .cpp under
# midisynth/src (outside src/output and src/bindings, which are its own CLIs
# and its own embedding) must appear below, in COMPILED or in EXCLUDED with a
# reason. A new one appears in neither, and the build stops.
#
# The same list must appear in CMakeLists.txt and in scripts/build_wasm.sh,
# which is the other half of what the check enforces: native and wasm must
# compile the same DSP or the determinism gate is comparing two different
# programs.

# ---------------------------------------------------------------------------
# This project's OWN sources, per build target.
#
# The sections above track midisynth's DSP, which is borrowed. These track
# ours, which is written here -- and they exist because check 4 only ever
# looked at the $SYNTH_DIR paths, so nothing proved CMakeLists.txt and
# build_wasm.sh agreed about the files this project itself compiles. With three
# targets instead of two that gap widens rather than staying still.
#
# The invariant that carries the most weight is check 6:
#
#     OWN_WASM_TOOL \ OWN_WASM_ENGINE == exactly { src/fit/fit.cpp,
#                                                  src/bindings/embind_fit.cpp }
#
# run_goldens.sh renders every golden case through the native binary, through
# dsound.mjs and through dsound-tool.mjs and requires all three to hash the
# same. That is only evidence about the fitter if the two modules differ by the
# fitter ALONE. Let anything else drift in and the leg keeps passing while
# proving something much weaker than it claims: not "the same engine plus a
# fitter", but "two different programs that happen to agree".
# ---------------------------------------------------------------------------
